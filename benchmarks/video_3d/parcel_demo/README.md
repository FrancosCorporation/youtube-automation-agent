# Piloto histórico de encomendas — fora do padrão de produção

Este piloto antecede a aprovação dos [humanos GLB do reflorestamento](../reforestation_demo/README.md). O elenco Game Farma da revisão original e o experimento posterior de humanos procedurais foram rejeitados. Nenhuma das duas variantes é referência vigente nem fallback da produção.

O checkout mantém alterações locais experimentais com `ProceduralHuman`, separadas do catálogo de produção. Fontes, modelos, movimentos, QA, renders e mudanças locais foram preservados; esta consolidação não os aprova, integra ou reverte. Não restaurar o antigo `RiggedHuman` para reintroduzir o elenco rejeitado.

O [README anterior integral](../../../docs/archive/alinhamento-2026-11-02/benchmarks/video_3d/parcel_demo/README.md) conserva comandos, medidas e proveniência histórica; havia descrições conflitantes de GLB e procedural. Não usar seus hashes/aceites para uma variante de bytes diferentes. A release v2.17.0 documenta reflorestamento, não uma aprovação posterior deste experimento.

Para produção, seguir [decisões vigentes](../../../docs/decisoes-vigentes.md), [direção criativa](../../../docs/padrao-criativo-aprovado.md) e [plan.md](../../../plan.md). Este documento não dispara render nem publicação.
