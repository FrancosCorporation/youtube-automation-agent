# v2.19.0 — seis minutos ou mais no YouTube

## Padrão de produção

- Master principal horizontal 16:9: alvo de 950 palavras narradas, com piso editorial de 850 palavras.
- A narração medida precisa ter ao menos 360 segundos antes de autoria de cenas e render; o uploader também retém qualquer master YouTube abaixo de seis minutos.
- A seleção automática busca contexto-fonte longo o suficiente para sustentar a explicação. Pautas curtas são registradas e substituídas quando não há base factual para desenvolver o tema.
- Roteiros longos são distribuídos em até sete seções. Cada frase é vinculada a uma ação, transformação ou plano de câmera pelo contrato visual existente.
- O master vertical 9:16 continua separado do horizontal; `makeNarrativeSocialParts` produz dele os cortes verticais para Shorts e outras redes. O piso de seis minutos vale só para o master YouTube.
